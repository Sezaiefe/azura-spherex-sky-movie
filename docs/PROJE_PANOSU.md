# Proje Panosu Onerisi (GitHub Projects)

GitHub deposunda **Projects -> New project -> Board** ile su 5 kolonlu pano acilin:

| Kolon | Anlamı |
|---|---|
| Backlog | Yapilacak ama bu sprintte planlanmayan isler |
| To Do | Bu sprintte yapilacaklar (sprint hedefleriyle es) |
| In Progress | Uzerinde calisilan (ayni anda 1-2 kart) |
| In Review / Test | Test edilmis, kod review bekleyen |
| Done | Bitmis ve dogrulanmis |

Kartlar issue olarak acilir; her sprint raporundaki "tamamlanan" kalemleri Done kolonundaki kartlara karsilik gelir.
